# Investix V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a private, Dockerized portfolio ledger with one-shot STOCKS-26 import, valuation/performance calculations, configurable market-data adapters, and an Italian responsive dashboard.

**Architecture:** A React/Vite SPA uses an authenticated FastAPI API. FastAPI owns the ledger domain, PostgreSQL persistence, import workflow, and provider abstraction; a separate worker persists observations and signals refreshes. The UI reads persisted data and uses Mantine Core plus Apache ECharts, remaining usable at an iPhone viewport.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy, Alembic, PostgreSQL 16, pytest; React, TypeScript, Vite, Mantine Core, Apache ECharts, Playwright; Docker Compose.

**Spec:** `docs/superpowers/specs/2026-10-13-investix-design.md`

## Global Constraints

- Italian UI, `it-IT` formatting and EUR base currency.
- Historical exports are read-only import/reconciliation input, never a runtime dependency.
- Ledger corrections/audits are non-destructive; derived metrics are recalculated.
- Average-cost accounting is per ticker/account; unknown optional dividends/fees remain nullable.
- Price/FX observations retain provider, raw/normalized data, units, timestamps and staleness.
- First release is EOD, Docker-local on Mac mini, private through Tailscale; browser never receives provider secrets.
- UI must work at desktop and at a 390 × 844 iPhone viewport with keyboard access and visible focus.

## Review Focus

- Same-day operations must use a deterministic source row/order so cost and realised P&L are reproducible.
- A total sale must retain realised P&L while exposing zero open quantity/cost.
- GBX must be divided by 100 before historical GBP/EUR conversion.
- Missing optional fee/dividend data must remain unknown, not be displayed as a fabricated zero.
- A price gap or stale provider response must remain visible rather than being labelled current.
